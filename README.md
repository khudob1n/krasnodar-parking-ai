# Парковки Краснодара (сделано ИИ)

Альтернативное приложение для оплаты городских парковок Краснодара.
Весь код в этом репозитории написан ИИ (Claude) как эталон: по нему автор
затем пишет свой проект руками.

## Каталоги

- `backend/` - API на Go и импорт данных
- `data/` - выгрузка зон с parkingkrd.ru (`zones.json`)
- `deploy/` - запуск на сервере: Docker Compose, Postgres, HTTPS через Caddy
- `mobile/` - клиент на Kotlin Multiplatform (появится позже)
