# Бэкенд

Go + Postgres/PostGIS. Миграции лежат в `internal/db/migrations` и применяются
автоматически при старте `api` и `import-zones`.

## Запуск

```sh
cd backend
make db-up     # поднять Postgres с PostGIS в Docker
make import    # загрузить зоны из ../data/zones.json
make run       # API на :8080
make test      # тесты (интеграционные ходят в ту же базу)
```

## API

- `GET /healthz` - жив ли сервер и база
- `GET /api/v1/zones/{number}` - зона по номеру с таблички
- `GET /api/v1/zones/nearby?lat=45.0355&lon=38.9753&radius=500&limit=20&kind=street,lot` -
  зоны рядом, ближайшие первыми. Расстояние считается до ближайшего участка улицы.
  `radius` до 5000 м (по умолчанию 500), `limit` до 100 (по умолчанию 20), `kind` необязателен.
- `GET /api/v1/zones/{number}/price?minutes=90&start=2026-10-13T18:00:00+03:00` -
  сколько стоит стоянка. `start` необязателен (по умолчанию сейчас). Оплата
  поминутная по местному времени, бесплатные часы не оплачиваются, сумма
  округляется вверх до копейки.

### Вход

Вход по номеру телефона и SMS-коду. Пока SMS-шлюза нет, код пишется в лог API
(строка `SMS not sent, dev mode`).

- `POST /api/v1/auth/code` `{"phone": "+7 918 123-45-67"}` - отправить код (не чаще раза в минуту, 429 с `Retry-After`)
- `POST /api/v1/auth/verify` `{"phone": "...", "code": "1234"}` - войти; ответ: `accessToken` (15 минут), `refreshToken` (30 дней), `user`
- `POST /api/v1/auth/refresh` `{"refreshToken": "..."}` - новая пара токенов, старый refresh больше не работает
- `POST /api/v1/auth/logout` `{"refreshToken": "..."}` - выйти
- `GET /api/v1/me` с заголовком `Authorization: Bearer <accessToken>` - текущий пользователь

Код живёт 5 минут, на него 5 попыток. Для API обязательна переменная
`JWT_SECRET` (не короче 32 символов); `make run` подставляет тестовую.

### Автомобили

Все ручки требуют `Authorization: Bearer <accessToken>`.

- `GET /api/v1/vehicles` - мои машины
- `POST /api/v1/vehicles` `{"plate": "а 123 вс 93", "title": "Киа"}` - добавить. Номер
  приводится к виду `А123ВС93`, латиница заменяется кириллицей. 409, если номер уже добавлен.
- `DELETE /api/v1/vehicles/{id}` - удалить

### Карты

Номер карты наш API не видит. Приложение отдаёт его платёжному провайдеру,
получает токен и привязывает карту по токену. Пока настоящего провайдера нет,
работает тестовый fakepay внутри того же сервера.

- `POST /fakepay/v1/tokens` `{"number": "4242 4242 4242 4242", "expMonth": 12, "expYear": 2030, "cvc": "123"}` -
  токен карты (без авторизации, это «провайдер»). Ответ 201: `token`, `last4`, `brand` (`mir`, `visa`,
  `mastercard`, `card`), `expMonth`, `expYear`. 400: `card number is invalid` (16 цифр, Луна),
  `expiry date is invalid`, `card is expired`, `cvc must be 3 digits`.
- `GET /api/v1/cards` - мои карты, старые первыми
- `POST /api/v1/cards` `{"token": "tok_..."}` - привязать. 400 `unknown card token`, 402 `card declined`,
  409, если токен уже привязан.
- `DELETE /api/v1/cards/{id}` - отвязать; можно и ту, которой платится парковка

Тестовые карты (срок - любой будущий, CVC - любые 3 цифры):

| Номер | Что будет |
|---|---|
| `4000 0000 0000 0002` | отказ и при привязке, и при оплате (`card declined`) |
| `4000 0000 0000 9995` | привязывается, но оплата не проходит (`insufficient funds`) |
| любой другой верный, например `4242 4242 4242 4242`, `2200 0000 0000 0004`, `5555 5555 5555 4444` | всё проходит |

### Парковки

Все ручки требуют `Authorization: Bearer <accessToken>`. Суммы в копейках.

- `POST /api/v1/sessions` `{"zone": 1103, "vehicleId": 1, "minutes": 60, "cardId": 1}` - начать и
  сразу списать стоимость до `plannedEnd`. `cardId` необязателен (по умолчанию последняя
  добавленная карта). 400 для бесплатной зоны, 409, если эта машина уже где-то стоит, 402
  `add a payment card first`, если карт нет, и 402 с текстом банка, если списание не прошло
  (тогда парковка не создаётся).
- `GET /api/v1/sessions?limit=20` - мои парковки, свежие первыми
- `GET /api/v1/sessions/{id}` - одна парковка
- `POST /api/v1/sessions/{id}/extend` `{"minutes": 30}` - продлить (всего не больше 24 часов) и
  доплатить картой парковки. 402, если не списалось или карту удалили.
- `POST /api/v1/sessions/{id}/stop` - остановить сейчас; платишь только за фактическое время,
  разница возвращается на карту
- `POST /api/v1/sessions/{id}/pay` `{"cardId": 2}` - оплатить долг завершённой парковки
  (`cardId` необязателен). 402, если снова не списалось, 409 `nothing to pay`, если долга нет.

Два режима, поле `mode` при старте (по умолчанию `prepaid`):

- `prepaid` - платишь вперёд за `minutes`, лишнее возвращается при остановке.
- `postpaid` - `minutes` не нужен, карта только проверяется, итог списывается при
  остановке. `plannedEnd` - через 24 часа, тогда парковка закроется сама со
  списанием. Продлить нельзя (400 `postpaid parking has no end time`). Если итог
  не списался, парковка всё равно завершается (200), а в ответе `debt` и `paymentError`.
  Пока долг не оплачен, новую парковку не начать: 402 `pay for the previous parking first`.

`cost` у активной парковки - сколько выйдет, если стоять до `plannedEnd` (у
постоплатной - сколько набежало сейчас); у завершённой - итог. `paid` - сколько
списано с карты за вычетом возвратов, `debt` - сколько ещё должны, `cardId` -
карта (null, если её удалили). Тариф запоминается при старте. Если парковку не
остановили, она заканчивается в `plannedEnd` сама. Все списания и возвраты
записываются в таблицу `payments`.

### Напоминания

API раз в 30 секунд проверяет парковки: за 10 минут до конца шлёт «Парковка скоро
закончится», в момент окончания - «Время парковки вышло», и закрывает истёкшие
парковки. После продления напоминание придёт снова. По постоплатным парковкам
напоминаний нет. Пока push-сервиса нет,
уведомления пишутся в лог (`push not sent, dev mode`).

- `POST /api/v1/devices` `{"token": "...", "platform": "android|ios|rustore"}` - привязать устройство
- `POST /api/v1/devices/unregister` `{"token": "..."}` - отвязать (при выходе из аккаунта)

## Данные зон

`parkingForm` из выгрузки сайта переводится в `kind`:
`1` - `street` (вдоль улицы, есть участки), `0` - `lot` (площадка, одна точка),
`2` - `free` (бесплатная). Цена хранится в копейках. `paidFrom` и `paidTo`
равны `00:00` - тариф круглосуточный. Поля `freeCount` и `placeUpdate`
не импортируются: на сайте это заглушки (свободно всегда = всего мест).

## Переменные окружения

- `DATABASE_URL` - строка подключения к Postgres с PostGIS.
- `JWT_SECRET` - секрет подписи токенов, не короче 32 символов.
- `HTTP_ADDR` - адрес сервера; если не задан, берётся порт из `PORT` (его задают хостинги), иначе `:8080`.
- `IMPORT_ZONES_FILE` - путь к выгрузке зон: при старте API загрузит их, если в базе зон ещё нет. В Docker-образе выгрузка лежит в `/data/zones.json`.
- `ACCESS_TOKEN_TTL` - срок жизни access-токена, по умолчанию `15m`.
