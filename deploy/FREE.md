# Бесплатный хостинг: Render + Neon

API работает на бесплатном веб-сервисе Render, база - на бесплатном Postgres от Neon
(в нём есть PostGIS, и бесплатная база не удаляется через месяц, как у Render).
Карта банковская не нужна ни там, ни там.

Ограничения бесплатного тарифа:

- Render усыпляет сервис после 15 минут без запросов. Первый запрос после сна ждёт
  около минуты, пока сервер проснётся. Для проверки приложения это нормально, для
  настоящих пользователей - нет. Чтобы он не засыпал, workflow `keepalive` в GitHub Actions
  раз в 10 минут открывает `/healthz` по адресу из переменной репо `API_BASE_URL`.
- Пока сервис спит, не работает и фоновая рассылка напоминаний с сервера. Напоминания
  в приложении локальные, их это не касается.

## 1. База на Neon

1. Зайти на https://neon.tech, войти через GitHub.
2. Create project: имя `krasnodar-parking`, Postgres 16, регион `AWS Europe Central 1 (Frankfurt)`
   - рядом с Render, запросы будут быстрее.
3. На странице проекта нажать **Connect**, выключить переключатель **Connection pooling**
   и скопировать строку подключения. Она вида
   `postgresql://neondb_owner:...@ep-...eu-central-1.aws.neon.tech/neondb?sslmode=require`.

   Строка без пулинга важна: через пулер Neon не работают блокировки, которыми бэкенд
   защищает миграции.

PostGIS включать руками не нужно: бэкенд сам выполнит `CREATE EXTENSION postgis` при первом старте.

## 2. API на Render

1. Слить в `main` PR бэкенда (#1-#8) и PR с этим файлом.
2. Зайти на https://render.com, войти через GitHub и дать доступ к репозиторию
   `krasnodar-parking-ai`.
3. **New > Blueprint**, выбрать репозиторий. Render прочитает `render.yaml` и спросит
   значение `DATABASE_URL` - вставить строку из Neon.
4. **Apply**. Первая сборка Docker-образа идёт несколько минут. При первом старте бэкенд
   создаст таблицы и загрузит 1716 зон из `data/zones.json`.
5. Адрес сервиса - на его странице, вида `https://krasnodar-parking-api.onrender.com`.
   Проверить: открыть `https://.../healthz` - должно быть `{"status":"ok"}`,
   и `https://.../api/v1/zones/1101` - зона с Красной.

`JWT_SECRET` Render сгенерирует сам. Каждый пуш в `main` пересобирает и перезапускает сервис.

## 3. Приложение на этот адрес

В репозитории на GitHub: **Settings > Secrets and variables > Actions > Variables >
New repository variable**, имя `API_BASE_URL`, значение - адрес с Render без `/` на конце.
После этого APK из GitHub Actions ходит на сервер, а не на `127.0.0.1`.

Код входа из SMS, пока нет SMS-шлюза, виден в логах сервиса на Render (вкладка **Logs**,
строка `SMS not sent, dev mode`).
